# 📖 Voice of the Forgotten (VOF)

**Voice of the Forgotten (VOF)** is the official web application for reading the original novel created by **Light** under **Light Web Official**.

The platform is designed to provide an immersive reading experience with a modern interface, smooth animations, secure content delivery, community features, and continuous updates.

---

## ✨ Features

* 📚 Modern eBook Reader
* 🌙 Responsive & Dark Theme UI
* ❤️ Like System
* 👁️ View Counter
* 💬 Community Discussions & Comments
* 🎉 GIFs, Emojis & Stickers
* 💖 Donate Support
* 🔒 Protected Reading Experience
* 📱 Mobile & Desktop Support
